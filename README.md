# Log Analyzer AI

## Description

A Python tool that reads log files, counts log categories, and generates a summary report.

## Features

* Read logs from a text file
* Count INFO logs
* Count ERROR logs
* Count WARNING logs
* Generate a summary report file

## Technologies Used

* Python

## Example Output

INFO: 2

ERROR: 2

WARNING: 1

## Future Improvements

* Support additional log types
* Filter logs by category
* Export reports to CSV
